# MakeHabit 要件定義書

習慣化を可視化するスマホブラウザ向けWebアプリ。決めたことをやったらスタンプを押し、累計日数と連続回数を表示する。続けていると褒めてくれる。友達とルームを作り、同じ習慣に一緒に取り組める。

- 想定ユーザー：自分と友達数人
- 対応環境：スマホのブラウザ（iOS Safari / Android Chrome）。PWAとしてホーム画面に追加できる
- 言語：日本語

---

## 1. 用語

| 用語 | 意味 |
|---|---|
| 習慣 | ユーザーが続けたいこと（例：毎朝ランニング） |
| 実施日 | 習慣ごとに設定した、実施する曜日に当たる日 |
| スタンプ | ある日に習慣をやったという記録。1習慣につき1日1個 |
| 後押し | 当日以外（過去7日以内）に押したスタンプ |
| 累計 | スタンプが押された日の合計数 |
| 連続 | 実施日だけを数えた、途切れずにスタンプが続いている回数 |
| ルーム | 友達と同じ習慣に取り組むグループ。1ルーム1習慣 |
| オーナー | ルームの管理者。最初はルームを作った人。退出時に他のメンバーへ引き継げる |

---

## 2. 機能要件

### 2.1 ログイン

- Googleログインが必須。ログインしていないと何も使えない
- 初回ログイン時に表示名を登録する（初期値はGoogleアカウントの名前）。後から変更できる

### 2.2 習慣

- 1人10個まで登録できる（ルームの習慣も含む。アーカイブしたものは含まない）
- 設定項目
  - 名前（必須、30文字以内）
  - 実施する曜日（月〜日から1つ以上選ぶ）
  - アイコン（絵文字）と色（任意）※暫定
- 編集：名前・曜日・アイコン・色を変更できる
- 曜日を変更した場合、**変更日以降にだけ新しい設定を適用**し、それより前の日は当時の設定で判定する（曜日設定の履歴を保存する）
- 削除とアーカイブ ※暫定
  - アーカイブ：記録を残して閲覧だけできる状態にする。10個の上限には数えない
  - 削除：記録ごと完全に消す（確認ダイアログを出す）

### 2.3 スタンプ

- 1習慣につき1日1個押せる
- **1日の区切りは午前3時**（午前0時〜2時59分は前日として扱う）。タイムゾーンは日本時間（Asia/Tokyo）に固定 ※暫定
- 押せる日
  - 今日
  - 直近7日以内の過去の日（今日を含まず、7日前まで）
  - 実施日でない日も押せる
- 押せない日
  - 未来の日
  - 習慣を作った日より前の日（ルームの習慣は、ルームに参加した日より前の日）
  - 8日以上前の日
- 取り消し：押せる期間内（今日と過去7日以内）なら取り消せる
- 後押しのスタンプは、当日に押したものと見た目を少し変える（薄くするなど）。ルームの友達からも区別できる

### 2.4 累計・連続の計算

表示する数字は **累計・現在の連続・最長連続** の3つ。

#### 累計

- スタンプが押された日の数。実施日かどうかは関係なく数える

#### 連続

- **実施日だけ**を並べ、スタンプが途切れずに続いている回数を数える。表示は「◯回連続」
- 実施日でない日は飛ばす。スタンプがあってもなくても、連続は伸びないし途切れない
- **今日が実施日でまだ押していない場合**は「途中」とみなし、途切れ扱いにしない
- 過去の実施日に押し忘れがあると、その時点で途切れたと表示する。過去7日以内なら後押しで埋められ、埋めれば連続は復活する
- 実施日かどうかは、その日に有効だった曜日設定で判定する

#### 計算例（月・水・金の習慣）

| 日 | 月 | 火 | 水 | 木 | 金(今日) |
|---|---|---|---|---|---|
| 実施日 | ○ | – | ○ | – | ○ |
| スタンプ | ✅ | ✅ | ✅ | | （未） |

- 累計：3（火も数える）
- 現在の連続：2回（月・水。今日の金はまだ途中なので途切れない）

#### 計算のしかた

1. 習慣の開始日から今日まで、各日が実施日かどうかを判定する
2. 現在の連続：今日から過去に向かって実施日をたどる。今日が未スタンプなら今日を飛ばす。スタンプのある実施日を数え、スタンプのない実施日に当たったら止める
3. 最長連続：全期間で、スタンプのある実施日が続いた最大の回数

※ 数人規模なので、表示のたびにスタンプ一覧から計算する。集計値はDBに保存しない。

### 2.5 褒める機能

- スタンプを押すたびに、定型文からランダムに選んだ一言を表示する
  - 例：「ナイス！」「今日もえらい！」「その調子！」
- 節目に達したときは、紙吹雪などの派手な演出とともに専用メッセージを出す
  - 連続：3・7・14・30・50・100回（以降100回ごと）
  - 累計：10・30・50・100・200・365日（以降100日ごと）※暫定
  - 例：「7回連続達成！1週間続いたね🎉」
- 後押しで連続が復活したときは「連続復活！」と表示する
- 長い間空いた後に再開したときは「おかえり！」と表示する ※暫定（例：直前の実施日7回分すべて未スタンプだった場合）
- 褒め言葉はアプリ内に定型文として持つ（AIは使わない）

### 2.6 画面表示

- ホーム：自分の習慣一覧（個人とルームの習慣を並べて表示）
  - 各習慣に今日のスタンプボタン、現在の連続、累計を表示
  - 今日が実施日でない習慣は「今日はお休み」と表示する（押すことはできる）
- 習慣の詳細：**月カレンダー**にスタンプを表示する
  - 実施日、実施日のスタンプ、実施日以外のスタンプ、後押しのスタンプ、押し忘れを見分けられるようにする
  - 前の月・次の月に移動できる
  - 押せる日（今日と過去7日以内）をタップすると、スタンプを押したり取り消したりできる
  - 累計・現在の連続・最長連続を表示する

### 2.7 ルーム

#### 基本

- 1ルーム1習慣。ルームの習慣名・アイコン・色はオーナーが決める
- 習慣名・アイコン・色を変更できるのはオーナーだけ（変更はメンバー全員の習慣に反映される）
- **実施する曜日は各メンバーが自分で決める**（参加時に設定し、後から変更できる）
- ルームの習慣は各メンバーの10個の上限に含まれる。上限に達している人は参加できない
- 1ルームの最大人数は10人 ※暫定
- 記録はルームに参加した日から数える

#### 招待

- オーナーが招待URLを発行し、LINEなどで送る
- URLを開いてGoogleログインし、曜日を選ぶと参加できる
- 有効期限はなし。オーナーがURLを作り直すと古いURLは無効になる

#### ルーム画面で見えるもの

- メンバー一覧
  - 今日の達成状況（✅ / ⬜ / 今日が実施日でなければ「お休み」）
  - 累計・現在の連続
  - 曜日設定（例：「Aさん：月水金」）
- 各メンバーのカレンダー（自分の詳細画面と同じ表示、閲覧のみ）
- リアクション：他のメンバーのスタンプに👏を送れる。もう一度押すと取り消せる
- **全員達成**：その日が実施日のメンバー全員がスタンプを押したら、ルームのカレンダーに特別なスタンプを付ける。実施日の人が0人の日は対象外
- ランキングは作らない

#### 退出

- メンバーはいつでも退出できる
- 退出したルームの習慣は、本人の手元にアーカイブとして残る（閲覧のみ）
- 退出した人はルーム画面のメンバー一覧から消える
- 退出した人は招待URLから再参加できる。再参加するとアーカイブした習慣が戻り、以前の記録も引き継ぐ（10個の上限に空きが必要）※暫定

#### オーナーの引き継ぎ

- オーナーが退出するときは、次のオーナーをメンバーの中から選ぶ。最初は参加日が一番古いメンバーが選ばれた状態にしておく ※暫定
- オーナー以外のメンバーがいない場合、オーナーの退出はルームの削除と同じ扱いになる（確認ダイアログを出す）

#### ルームの削除

- オーナーだけがルームを削除できる（確認ダイアログを出す）
- 削除すると、全メンバーのルームの習慣がアーカイブになり、それぞれの手元に記録が残る（閲覧のみ）※暫定
- 削除したルームの招待URLは使えなくなる

#### メンバーを外す

- オーナーだけが、ほかのメンバーをルームから外せる（確認ダイアログを出す）
- 外されたメンバーのルームの習慣は、本人の手元にアーカイブとして残る（閲覧のみ）
- 外されたメンバーは、招待URLを作り直しても再参加できない ※暫定

### 2.8 プライバシー

- 個人の習慣は本人しか見られない
- ルームの習慣は、そのルームのメンバーだけが見られる
- 他のメンバーに見えるのは、表示名・ルームの習慣のスタンプ・曜日設定のみ（メールアドレスは見せない）

## 3. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応端末 | スマホ縦向きを基本にする。PCでも崩れずに表示できる |
| PWA | ホーム画面に追加できる（アイコン、全画面表示） |
| 通知 | 初期版では作らない |
| 性能 | スタンプを押したらすぐに画面に反映する（サーバーの応答を待たずに表示を更新する） |
| セキュリティ | 全テーブルでSupabaseの行単位アクセス制御（RLS）を使い、自分のデータと所属ルームのデータにしかアクセスできないようにする |
| 費用 | 無料枠で運用する |
| ダークモード | 端末の設定に合わせる |

## 5. データ設計（案）

```
profiles            ユーザー
  id (= auth.users.id), display_name, created_at

rooms               ルーム
  id, name, icon, color, owner_id, invite_token, created_at, deleted_at (削除時に設定)

room_members        ルームのメンバー
  room_id, user_id, habit_id, joined_at,
  left_at (退出・外された時に設定), left_reason ('left' | 'removed' | 'room_deleted')
  ※ left_reason = 'removed' の人は再参加できない

habits              習慣（ルームの習慣は、メンバーごとに1行持つ）
  id, user_id, room_id (個人の習慣はNULL),
  name, icon, color (ルームの習慣は rooms の値をコピーして揃える),
  start_date (作成日 or ルーム参加日), archived_at, created_at

habit_schedules     曜日設定の履歴
  id, habit_id, weekdays (例：{1,3,5}), valid_from (適用開始日)

stamps              スタンプ
  id, habit_id, date (午前3時区切りの日付), stamped_at (押した日時),
  is_late (後押しかどうか)
  ※ (habit_id, date) で一意

reactions           リアクション
  stamp_id, user_id, created_at
  ※ (stamp_id, user_id) で一意
```

- ある日が実施日かどうかは、`valid_from` がその日以前で最も新しい `habit_schedules` の行で判定する
- ルームの名前・アイコン・色はメンバーの習慣にコピーしておくので、ルームが削除されても習慣名を表示できる
- 「全員達成」は、ルームの各メンバーの習慣・曜日設定・スタンプから計算する（保存しない）

## 6. 画面一覧

| 画面 | 内容 |
|---|---|
| ログイン | Googleログインボタン |
| ホーム | 習慣一覧、今日のスタンプボタン |
| 習慣の作成・編集 | 名前、曜日、アイコン、色 |
| 習慣の詳細 | 月カレンダー、累計・現在の連続・最長連続 |

| ルームへの参加 | 招待URLから開く。ルーム名と曜日の選択 |

## 7. 開発の進め方

1. **フェーズ1：ひとりで使える**
   - Googleログイン、習慣の登録・編集、スタンプ、累計と連続、カレンダー、褒める機能、PWA
2. **フェーズ2：友達と使える**
   - ルームの作成、招待、参加、メンバー一覧、リアクション、全員達成、退出、オーナーの引き継ぎ、メンバーを外す、ルームの削除

---

## 8. 作らないもの

- アカウントの削除機能
- 通知（初期版）
- ランキング
- ルーム内のチャット・コメント

「※暫定」と書いた項目は、実装しながら必要に応じて見直す。
